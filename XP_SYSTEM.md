# Flourish XP System

## Core Philosophy
XP should reward:
- consistency
- learning
- course completion
- exploration
- simulator engagement

Avoid:
- grindy spam
- gambling-style dopamine
- childish/cringy gamification

## Visual Reinforcements
- Tiny level badge beside profile
- XP progress bar and count on dashboard
- 'Gained XP' animations after completing a successful XP Reward, for example a +25XP animation
- Streak flame icon, positively reinforce users unlocking successive days of platform use
- 'Level-up!' modal after reaching the next level threshold

## XP Rewards

### Courses
- Complete lesson: +20 XP
- Pass quiz first try: +15 XP
- Complete course: +100 XP

### Simulator
- First trade: +20 XP
- First profitable sale: +15 XP
- Diversify portfolio into three sectors: +35 XP
- Hold an ETF: +15 XP
- Complete first profitable month: +50 XP

## Streaks
- 3 day streak: +25 XP
- 7 day streak: +50 XP
- 14 day streak: +100 XP
- 30 day streak: +250 XP
